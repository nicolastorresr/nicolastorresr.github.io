# Nicolás Torres — Personal Portfolio

This repository contains the static website for **https://nicolastorresr.github.io/**.

## Deploy with GitHub Pages

1. Create a new public GitHub repository named exactly:
   `nicolastorresr.github.io`
2. Upload `index.html`, `style.css` and `script.js`.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.
5. Your portfolio will be available at:
   `https://nicolastorresr.github.io/`

## Optional CV

Place your PDF CV in the repository root with the filename:

`cv.pdf`

The CV button in the navigation will then work automatically.
